# 依赖与接入清单

更新：2026-10-18。此文件记录C04依赖、配置边界和待查项；当前版本、验证结果及换板前事项见[换板前工作清单](换板前工作清单.md)。

## 已锁定依赖

- UI：LVGL9.4.0，commit `c016f72d4c125098287be5e83c0f1abed4706ee5`；Zig0.14.1；现有字体子集仍仅用于私人预览。
- JSON：cJSON1.7.19，MIT许可证；源码与许可证在vendor/cjson，编译解析深度限制32，输入上限32KiB，模型不持有JSON解析树。
- GSW：.NET SDK10.0.402、运行时10.0.13、Windows x64，项目内工具安装；global.json和gsw/packages.lock.json锁定构建。发布为包含运行时的单个GSW.exe，用户无需另装.NET10。CPU后端依赖LibreHardwareMonitorLib0.9.6和官方签名PawnIO；不引入NVML托管包。
- GSN：Go1.27.2、标准库及锁定的coder/websocket v1.8.15（ISC，已vendor）、CGO关闭的Linux ARM64静态程序；无Redis、数据库、Python或常驻反向代理。
- TLS根证书：curl从Mozilla导出的2026-09-25根证书包，供scratch镜像内HTTPS客户端使用；来源及校验和见toolchains.lock.json。
- 开发校验：contracts/requirements-dev.txt锁定Python依赖，不进入GSW或GSN运行环境。本地`work/contract-deps`含原生扩展，切换Python小版本后须用同一个解释器执行`python -m pip install --upgrade --only-binary=:all: --target work/contract-deps -r contracts/requirements-dev.txt`再运行校验，不能跨3.10/3.11直接复用二进制扩展。

## 数据口径与实体

- CPU：GetSystemTimes总负载，RAM=TotalPhysical-AvailablePhysical；GPU按GpuIndex选择NVML设备，VRAM为专用显存。3900X温度与Package功耗已由受保护CPU任务采集；权限与长稳边界见CPU温度与功耗.md。
- 磁盘：配置最多三个逻辑盘；每秒读容量，总可用空间采用TotalFreeSpace；物理型号经存储IOCTL读取，最多缓存60秒。权限失败/多物理盘映射时型号可为空，不硬套历史型号。
- BX54：http://192.168.124.1/mobile.asp，wan_rate第一项上传、第二项下载，B/s；固定缓冲流式读取，正常目标≤2KiB、硬限制8KiB，总HTTP超时800ms。真实页面刷新周期约5秒已有证据，内部速率计量窗口未完全核实；NAS资源/读取量验收保留。
- Codex额度：GSW0.1.5优先复用本用户JSONL的token_count.rate_limits，明确limit_id、window_minutes、used_percent与resets_at；仅接受90秒内事件，保留原观测时刻及单调年龄。日志不可用/过期时保留只读短生命stdio app-server回退，initialize/initialized/account/rateLimits/read，每60秒最多一次；不发模型任务、不读认证文件。冷启动最多等40秒日志回溯。额度异常不改变任务状态，RPC峰值预算仍待验收。

- Codex任务：仅本用户最近3个日期目录、最多32份JSONL元数据，最多4条摘要。正常扫描无活动任务为idle，读取失败为unknown；GSW0.1.4已从会话索引读取真实标题并计算任务持续时长；最多8MiB/文件回溯、256KiB/次扫描，完整客户端验收仍待完成，不以合成名称代替。不上报聊天正文，不宣称能观察所有云端任务。额度和任务状态独立。
- Claude额度与任务：桌面版额度由GSW0.1.15读取（`ClaudeUsageApi`，默认关闭）——本地优先读`%APPDATA%\Claude\plan-usage-history.json`，重置时间等按需请求`api.anthropic.com/api/oauth/usage`，令牌取自桌面版`config.json`的`oauth:tokenCacheV2`（DPAPI解密，仅内存使用，不刷新、不落盘、不写日志）；终端版用statusLine桥接。任务状态读`~/.claude/projects`的JSONL，最近3天、最多32份。范围、频率与限制见[版本记录](版本记录.md)。
- 字体与图标生成（仅在改文字或图标时）：Python Pillow和系统SimHei用于`scripts/generate_font.py`；`scripts/generate-provider-icons.ps1`读取本机已安装的Codex与Claude桌面应用自带图标。

## NAS已确认与待验收

用户确认：RK3566、2GB RAM、90GB eMMC、aarch64、hdd0实际路径、2000–3000空闲端口。交付采用host网络、0.0.0.0:2780，`/hdd0/GSN/config → /app/config`读写挂载，无端口映射。仍须用户在GUI核对目录读取权限及现有HA/DNS/DHCP的资源基线；镜像导入、启动和回滚均手动。

GSN只记录启动/退出类进程日志，不逐条记录正常遥测；Docker日志配置10MiB×3。读取和写入使用不同令牌；配置与NAS客户端profile已生成在忽略目录，不进入源代码。

HA优先使用单个WebSocket定向订阅，只保留配置实体及必要属性；认证/订阅失败或断线时按各来源策略定向REST回退，命令确认始终只查询目标。WebSocket消息上限64KiB、启动截止2秒，15秒协议心跳，断线退避2–60秒；不支持订阅/认证失败退避5分钟。心跳仅更新连接观测时间，保留实体原始更新时间。可设ha.websocket=false回退REST。CLASH健康以真实/version成功且版本字段有效为依据。当前VPN总量按用户确认的200G、与HA余额同GiB口径计算比例，每月24日重置；缺失或无效余额仍保持不可用。
