# GSS Wi-Fi直连

当前显示端0.7.24；下文0.7.0/0.7.1为旧板验证记录，新板尚未验收。当前发布与待办见[换板前工作清单](换板前工作清单.md)。

## 使用

上电后自动连接已保存的Wi-Fi，随后直接访问GSN。无需启动电脑桥接程序。主页左侧标题右边的Wi-Fi图标，绿色表示已获取IP，暗黄色表示无线就绪但未连接，红色表示无线尚未就绪；点击图标可进入Wi-Fi设置。底部原有状态文字继续区分网络离线、GSN离线/认证失败/响应异常和GSW来源状态。

Wi-Fi页（侧栏Wi-Fi图标，或“设置 → 管理 Wi-Fi”，从设置进入时“返回”回到设置）左侧是附近网络列表，进入页面时自动扫描一次，点选后自动填入网络名并区分开放/加密；右侧是连接状态、网络名与密码输入、“连接”“断开”“忘记”。三个按钮只在可用时亮起：网络名有效才能连接，已连接才能断开，有已保存网络才能忘记；输入密码时键盘覆盖在下方，完成后收起。扫描最多保留12条记录并合并同名网络。密码保存在设备NVS，不编入固件。单次连接失败最多快速重试3次，随后每60秒重新尝试；手动断开会停止自动重连，重启后恢复默认连接。

## GSN 配置

当前实例为 `http://192.168.124.14:2780`。读取令牌和家电控制令牌来自本机私有 `config/display-nas.json`，保存到独立 `gsn_config` NVS分区（0x10000，24KiB）。它与Wi-Fi/亮度设置所在的原NVS分开，普通应用升级不覆盖配置。

首次配置或令牌变更时，加载 `scripts/esp-idf-env.ps1`，用配套Python运行 `scripts/gss-network-config.py`，将生成的 `work/private-gss-network/network.bin` 单独刷到0x10000。该文件包含私有令牌，不加入发布包。生成过程不输出令牌，临时CSV自动删除。设备屏幕只提供Wi-Fi配网，不显示或导出GSN令牌。0.7.4增加Mihomo控制配置mihomo_url、mihomo_token，一并从私有显示配置生成到同一NVS，不编入正式固件。

## 业务传输

- 每秒直接GET `/api/v1/snapshot`，响应最多32768字节；完整解析成功才交换最新快照。HTTP失败不覆盖最后一份有效数据；超时和来源过期分别展示。
- HTTP请求设置2秒超时，禁止跳转，不在GUI线程做网络I/O。无线恢复后自动恢复GSN读取；网络中断期间自动亮度回退保存的手动值。
- 家电操作由单独任务直接POST `/api/v1/home/commands`。每个意图使用独立请求ID和当前GSN控制epoch；队列超过2秒或epoch变化则拒绝发送。
- POST响应丢失后仅GET查询命令结果，不重放POST。操作回报校验命令ID、实体ID和动作；窗口反向/停止支持替代旧等待任务。原白名单、动作权限和过期时间检查保留。

USB桥接协议、接收任务、PC桥接脚本、临时串口配网入口和启动/停止桥接命令已删除。USB只用于供电、烧录和串口诊断，不承载业务数据。

## 硬件与分区

P4↔C5采用厂家指定SDMMC Slot1、1-bit、40MHz；D0=14、D1/IRQ=15、CLK=18、CMD=19、EN=54、BOOT=53。本块C5已有可用固件，未重新刷写C5或eFuse。P4使用本机ESP-IDF6.1及BOYA驱动。

当前源码的单factory应用从0x20000开始，大小15.875MiB，连续使用剩余Flash；分区避让已移除，换板后重新验收。不使用OTA双应用，不做整片擦除。普通升级文件与地址由 `artifacts/GSS/flash-manifest.json` 给出；目前已打包0.7.24，与最新构建同步。`artifacts/P4`仅为历史0.7.2包。
