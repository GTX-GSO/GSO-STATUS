# 售后寄回与开发交接

2026-10-17：开发板已寄回。主工程已删除售后说明页面、专用构建开关、Flash故障诊断程序及分区避让逻辑，不再提供旧板复测入口。

## 当前源码与分区

GSS（GSO STATUS SCREEN）0.7.3恢复正常单factory布局：nvs位于0x9000/24 KiB，phy_init位于0xF000/4 KiB，gsn_config位于0x10000/24 KiB，factory从0x20000连续使用至16 MiB末尾，容量0xFE0000（15.875 MiB）。没有故障保留分区，没有双OTA。

构建及烧录地址由ESP-IDF生成，打包脚本核对应用地址、对齐和容量，不再限制应用必须位于2 MiB之后。新布局和0.7.2历史布局不同，更换正常板后应使用同版bootloader、分区表和应用。

0.7.3包含前一轮动画改动：普通页面内容固定、仅标题局部过渡，退出和游戏启动使用短期静态缓存，缓存预算2 MiB。换板前只做构建与桌面自检，不提供新的实机帧率结论。

## 保留的资料

原厂16 MiB备份及厂家资料保持不变。Flash、BOYA板端、ROM无压缩复测报告和证据包属于历史资料，不作为正常板使用步骤。退役诊断源码、售后镜像与日志封存在artifacts/project-history/retired-flash-diagnostics.zip，主代码目录对应入口已删除。work内旧诊断构建缓存及临时工具目录不再由任何项目构建引用，其批量删除被自动审批拒绝。

旧板私有配置备份work/private-return-backup/nvs-before-return.bin含私有信息，不属于公开固件交付。更换正常板后重新配网并生成GSN配置，不盲目整片恢复旧板备份。
